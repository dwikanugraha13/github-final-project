# Simple Interest Calculator

This project is a simple interest calculator that computes the interest based on the principal amount, rate of interest, and time period.

## 📌 Introduction

A simple interest calculator is used to calculate the interest earned or paid over a specific period of time. This project demonstrates how to calculate simple interest using a basic formula.

## 🧮 Formula

The formula used to calculate simple interest is:

SI = (P × R × T) / 100

Where:
- **P** = Principal amount (initial money)
- **R** = Rate of interest (percentage)
- **T** = Time period (in years)

## ⚙️ How It Works

1. Enter the principal amount (P)
2. Enter the rate of interest (R)
3. Enter the time period (T)
4. The calculator applies the formula
5. The result (Simple Interest) is displayed

## ▶️ Example

If:
- Principal = 1000
- Rate = 5%
- Time = 2 years

Then:

SI = (1000 × 5 × 2) / 100 = 100
